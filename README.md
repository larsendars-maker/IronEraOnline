# Iron Era Online v0.6.1 — Fixed build

Исправлена главная проблема с пустым игровым экраном после входа:
- сервер отправляет полный snapshot сразу после выбора комнаты;
- `joined` теперь содержит состояние мира;
- клиент рендерит состояние даже если сообщения пришли в другом порядке;
- добавлен экран подключения вместо пустой карты;
- нельзя войти без никнейма;
- нельзя войти без выбранной страны;
- сервер повторно проверяет ник и страну;
- занятая страна блокируется;
- добавлено восстановление соединения после краткого обрыва;
- корректно переподключается к той же комнате;
- выход из кампании не оставляет старое соединение;
- кнопка входа в комнату блокируется, пока не заполнены ник и страна.

Запуск на Render:
`npm install`
`npm start`

Главная точка сайта — `/` (лобби/кампания в одном приложении).

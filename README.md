# Iron Era Online v0.5

Большой браузерный прототип глобальной стратегии: real-time WebSocket, онлайн-игроки, серверный ИИ, политическая карта, армии, производство, технологии, дипломатия, политика, разведка, чат и серверный тик.

## Что внутри
- Политическая карта с провинциями и режимами: политика / промышленность / снабжение / местность / погода.
- Несколько игроков в одном мире, никнеймы, онлайн-счётчик и мировой чат.
- Армии, дивизии, командиры, организация, сила, опыт, приказы движения и атаки.
- Бои зависят от местности, погоды, организации и боевой силы.
- Производство и строительство.
- Ресурсы, промышленность, TC/логистика.
- Исследовательские слоты и дерево технологий.
- Дипломатия, отношения, альянсы, войны и торговые сделки.
- Политические параметры.
- Разведывательные сети.
- ИИ экономического, дипломатического и военного уровня.
- Автоматические события и мировая хронология.
- Real-time WebSocket.
- Опциональное сохранение в PostgreSQL через `DATABASE_URL`.
- `/health` endpoint для Render.

## Локальный запуск
Node.js 20+:
```bash
npm install
npm start
```
Открыть `http://localhost:10000`

## Render
1. GitHub → новый репозиторий.
2. Загрузить содержимое проекта с этой структурой:
```text
package.json
server.js
render.yaml
README.md
public/
  index.html
  app.js
  style.css
```
3. Render → New → Web Service → выбрать репозиторий.
4. Runtime: Node.
5. Build Command: `npm install`
6. Start Command: `npm start`
7. Plan: Free для тестовой кампании.

## PostgreSQL
Для сохранения мира между перезапусками добавьте PostgreSQL и переменную окружения:
`DATABASE_URL=<строка подключения>`
Сервер сам создаёт таблицу `iron_world` и сохраняет snapshot.
Без DATABASE_URL игра работает в памяти процесса.

## Важно
Это большая playable-версия, но не клон коммерческой игры. Карта, страны, названия, технологии и контент сделаны как оригинальный игровой материал. Архитектура рассчитана на дальнейшее расширение.

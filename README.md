# Iron Era Online v0.6 — world map + mandatory country selection + national events

## Что исправлено
- Лобби получает список стран сразу при подключении, поэтому select больше не пустой.
- Войти нельзя без никнейма И страны.
- Занятая игроком страна автоматически блокируется.
- Сервер повторно валидирует никнейм и страну — обход через браузер невозможен.
- Если игрок выходит, страна снова становится доступна.
- Полностью переделана карта: 12 стран, 72 провинции, разные типы местности, столицы, ресурсы, промышленность и реальные соседства.
- На карте отображаются страны, никнеймы игроков, ИИ, армии, войны и провинциальные названия.
- Добавлены события стран с вариантами выбора и последствиями.
- События работают на сервере; для ИИ выбор производится автоматически.
- Сохранение мира через PostgreSQL при наличии `DATABASE_URL`.

## Национальные события
События — оригинальный игровой контент, вдохновлённый системой национальных событий глобальных стратегий:
- баннер/окно события;
- текст ситуации;
- 2 выбора;
- последствия для промышленности, стабильности, военной поддержки, денег, политики, флота, ВВС и отношений;
- события привязаны к датам кампании;
- выбранное событие повторно не появляется.

## Карта
Мир состоит из 12 вымышленных государств:
Аурория, Бореалия, Центрия, Дория, Элирия, Фронтера, Галлия, Гесперия, Иония, Кхарак, Лидрия, Меридия.
У каждого государства по 6 провинций.

## Render
- Build: `npm install`
- Start: `npm start`
- Node 20+
- Optional PostgreSQL через `DATABASE_URL`

Загрузить содержимое архива в GitHub с этой структурой:
```text
package.json
server.js
render.yaml
README.md
public/
  index.html
  app.js
  style.css
```
После коммита Render с Auto Deploy сам перезапустит сервис.
